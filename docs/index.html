FIELD PROCEDURE

설치 후 바로 설정까지.

설치는 데스크톱에서, 네트워크 설정은 iPhone 또는 컴퓨터에서 진행할 수 있습니다. Wi-Fi가 저장되지 않은 C6는 부팅 즉시 설정용 AP를 엽니다.

!
USB 데이터 케이블이 필요합니다. 충전 전용 케이블은 전원만 공급하고 보드를 브라우저에 표시하지 않습니다.
  1. 01

    USB로 보드 연결

    Windows의 Chrome 또는 Edge에서 이 페이지를 열고 ESP 보드를 연결합니다.

  2. 02

    펌웨어 설치

    보드 카드의 설치 버튼을 누르고 브라우저의 직렬 포트 선택 창에서 ESP 포트를 고릅니다.

  3. 03

    Wi-Fi · MQTT 등록

    IOS-ANCS-SETUP-XXXXXX AP에 연결한 뒤 192.168.4.1에서 설정합니다.

BEFORE YOU FLASH

작은 확인이 보드를 지킵니다.

01 / MATCH

칩 모델 일치

C6 펌웨어는 ESP32-C6에만 설치하세요. WROOM-D32와 C3는 준비 중입니다.

02 / ERASE

초기화 선택 주의

전체 삭제를 선택하면 저장된 Wi-Fi, MQTT, iPhone 등록 정보가 사라집니다.

03 / POWER

설치 중 연결 유지

진행률이 끝날 때까지 USB 케이블을 뽑거나 브라우저 창을 닫지 마세요.

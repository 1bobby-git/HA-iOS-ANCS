01 / PREPARE

현장 준비

할 일

지원 보드, 데스크톱 Chrome 또는 Edge, USB 데이터 케이블, Wi-Fi, MQTT broker, iPhone, Home Assistant를 준비합니다.

성공 확인

이 페이지의 SECURE CONTEXT와 WEB SERIAL 상태가 준비 또는 브라우저 요구 사항을 명확히 표시합니다.

문제가 있으면

HTTPS Pages URL https://1bobby-git.github.io/HA-iOS-ANCS/을 열고 Chrome 또는 Edge로 다시 시도합니다.

02 / FLASH

보드 선택과 USB 플래시

할 일

ESP 모델을 선택하고 USB로 연결한 뒤 설치 버튼을 누릅니다. 전체 지우기는 Wi-Fi, MQTT, BLE bond를 제거한다는 점을 확인한 경우에만 선택합니다.

성공 확인

ESP Web Tools가 연결 칩을 감지하고 쓰기 완료를 표시합니다. 재부팅 후 설정 AP가 열릴 준비가 됩니다.

문제가 있으면

BOOT 버튼을 누른 상태로 설치를 다시 시작하거나, 다른 USB 포트와 데이터 케이블로 포트 감지를 확인합니다.

03 / PROVISION

설정 AP와 MQTT

할 일

IOS-ANCS-SETUP-XXXXXX AP에 연결하고 192.168.4.1을 열어 Wi-Fi와 MQTT broker 정보를 저장합니다.

성공 확인

보드가 사용자 Wi-Fi로 재접속하고 MQTT birth 또는 상태 토픽이 broker에 나타납니다.

문제가 있으면

SSID, 비밀번호, MQTT host, port, 사용자 정보를 다시 입력하고 broker 로그에서 연결 거부 사유를 확인합니다.

04 / HOME ASSISTANT

MQTT Discovery와 HACS 동반 통합

할 일

Home Assistant MQTT 통합과 Discovery를 켭니다. 필요하면 HACS 사용자 저장소로 https://github.com/1bobby-git/HA-iOS-ANCS를 추가합니다.

성공 확인

MQTT Discovery 엔티티가 나타나고 첫 알림 검증 자동화가 한 번만 실행됩니다. MQTT Discovery는 HACS 없이 동작합니다.

문제가 있으면

HACS는 ESP32를 플래시하지 않습니다. 펌웨어 문제는 이 설치기와 MQTT 로그에서, HA 동반 통합 문제는 HACS와 Home Assistant 로그에서 분리해 확인합니다.

05 / PAIR

iPhone 등록

할 일

BOOT 3초 누르기는 모든 보드에서 enrollment 창을 여는 공통 방법입니다. Home Assistant 등록 버튼은 MQTT Discovery가 control entity를 만든 뒤에만 나타납니다. enrollment 창이 열리면 iPhone에서 Bluetooth 페어링을 승인합니다. PIN은 123456입니다.

성공 확인

iPhone Bluetooth 목록에 장치가 유지되고 알림 공유가 허용됩니다. 첫 iOS 알림이 MQTT payload로 전달됩니다.

문제가 있으면

iPhone의 기존 Bluetooth 기록을 삭제하고 enrollment 창을 다시 연 뒤, 알림 미리보기와 Bluetooth 공유 권한을 확인합니다.

06 / TROUBLESHOOTING

증상별 복구

할 일

포트가 안 보이면 케이블과 브라우저를 바꾸고, AP가 안 보이면 재부팅 후 BOOT 흐름을 확인합니다. 알림이 없으면 iPhone 공유 권한, MQTT topic, HA 자동화를 순서대로 확인합니다.

성공 확인

보드 상태, MQTT payload, Home Assistant 엔티티, 첫 알림 전달 중 어느 지점에서 끊기는지 하나로 좁혀집니다.

문제가 있으면

전체 지우기는 마지막 복구 수단으로만 사용합니다. 선택하면 Wi-Fi, MQTT, BLE bond가 모두 삭제되므로 다시 프로비저닝하고 iPhone을 등록해야 합니다.

Home Assistant iOS ANCS Installer

ESP32가 iPhone 알림을 ANCS로 받아 MQTT를 통해 Home Assistant에 전달하도록 펌웨어를 설치합니다.

Apple Notification Center Service (ANCS): 블루투스(BLE)를 통해 아이폰 등의 iOS 기기 알림을 스마트워치나 이어폰 같은 주변 기기로 전달해 주는 애플 규격 서비스입니다

이 페이지는 ESP32 펌웨어 설치용입니다. HACS는 Home Assistant 동반 통합만 설치하며 ESP32 펌웨어를 설치하거나 업데이트하지 않습니다.

SETUP STEPS

설치 후 연결 절차

플래시, 설정 AP, Wi-Fi/MQTT 저장, Home Assistant Discovery, iPhone 페어링, 알림 확인 순서로 진행합니다.

!
HACS 경계 HACS는 Home Assistant 동반 통합만 설치합니다. ESP32 펌웨어 플래시와 업데이트는 이 브라우저 설치기 또는 소스 빌드 절차에서 수행합니다.

01 / FLASH

펌웨어 플래시

데스크톱 Chrome 또는 Edge에서 데이터 USB 케이블로 ESP32를 연결하고 보드 계열을 선택한 뒤 설치 버튼을 누릅니다. full erase는 Wi-Fi, MQTT, BLE bond를 모두 지우는 경우에만 선택합니다.

02 / SETUP AP

설정 AP 접속

플래시 후 IOS-ANCS-SETUP-XXXXXX Wi-Fi에 연결합니다. 비밀번호는 ancs-xxxxxx입니다. XXXXXX는 기본 Wi-Fi MAC 주소의 마지막 6자리 16진수이며, SSID에서는 대문자, 비밀번호에서는 소문자를 사용합니다. 이 값은 모델 번호가 아닙니다.

03 / PROVISION

Wi-Fi와 MQTT 저장

브라우저에서 http://192.168.4.1을 열고 Wi-Fi와 MQTT broker 정보를 저장합니다. 이 포털은 Home Assistant 설정을 저장하지 않고 ESP32의 네트워크 및 MQTT 접속 정보만 저장합니다.

04 / HOME ASSISTANT

MQTT Discovery 확인

ESP32가 broker에 연결되면 MQTT Discovery가 Home Assistant 장치와 iPhone 등록 시작 버튼을 생성합니다. HACS 동반 통합은 HACS My 링크로 추가할 수 있지만 펌웨어를 플래시하지 않습니다.

05 / PAIR

iPhone 페어링

BOOT을 3초 누르거나 Home Assistant의 iPhone 등록 시작 버튼을 눌러 120초 등록 창을 엽니다. iOS Bluetooth 목록에서 IOS-ANCS-... 장치를 선택하고 PIN 123456을 입력한 뒤 알림 공유를 허용합니다.

06 / VERIFY

알림 확인

Home Assistant에서 최근 알림과 앱 이름이 갱신되는지 확인합니다. iPhone의 ANCS Display Name을 우선 사용하며, 첫 조회 뒤에는 연결 세션 캐시를 사용합니다. 조회 실패 시에도 알림은 유지되고 정적 매핑과 원본 앱 ID로 폴백합니다. 폴백 대응표는 앱 ID 참고 문서를 확인하세요.

증상 확인
USB 포트가 보이지 않음 데스크톱 Chrome/Edge, HTTPS Pages, 데이터 USB 케이블을 확인합니다.
설정 AP가 보이지 않음 플래시 완료 후 재부팅을 기다리고, 필요하면 BOOT 버튼을 3초 눌러 복구 창을 엽니다.
포털이 열리지 않음 IOS-ANCS-SETUP-XXXXXX에 연결된 상태에서 http://192.168.4.1을 엽니다.
Home Assistant 장치가 없음 MQTT broker 접속, Discovery 활성화, retained config publish를 확인합니다.
iPhone이 보이지 않음 120초 등록 창과 iOS Bluetooth 권한을 확인합니다.
알림이 비어 있음 알림 공유 허용, iOS 알림 설정, MQTT payload를 확인합니다.

# iOS ANCS 0.6.9 / Firmware 0.3.8

Home Assistant용 iOS ANCS 통합 `0.6.9`와 ESP32 펌웨어 `0.3.8` 릴리스입니다.

## Home Assistant 통합 0.6.9

- 펌웨어 `0.3.8` 배포 상태와 통합 버전을 하나의 GitHub Release로 정리했습니다.
- 기존 MQTT Discovery 장치와 Home Assistant 보조 통합의 동작 및 엔티티 계약은 변경하지 않습니다.

## ESP32 펌웨어 0.3.8

- iPhone Bluetooth 페어링 PIN을 모든 지원 보드에서 `123456`으로 고정했습니다.
- 신규 페어링은 사용자가 연 120초 등록 창 안에서만 허용합니다.
- 펌웨어 `0.3.7`에 포함된 ANCS enroll 초기화 수정, Wi-Fi 재연결 및 AP/STA 안정성 개선을 모두 포함합니다.
- ESP32, ESP32-C2, ESP32-C3, ESP32-C5, ESP32-C6, ESP32-C61, ESP32-S3용 factory 이미지를 제공합니다.

## 배포 정리

펌웨어 `0.3.7`은 소스와 설치 페이지에는 반영됐지만 별도 태그와 GitHub Release로 공개되지 않았습니다. `0.3.8`이 해당 변경을 모두 포함하므로 `0.3.7`을 별도 공개하지 않고 이 릴리스로 대체합니다.

첨부된 `release-fingerprints-v0.3.8.sha256`으로 7개 factory 이미지의 SHA256을 검증할 수 있습니다.

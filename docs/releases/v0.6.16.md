# iOS ANCS 통합 0.6.16 / 펌웨어 0.4.1

## 바뀐 점 (펌웨어 0.4.1)

- **거부된 접속 뒤에도 광고를 다시 시작합니다.** 등록되지 않은 기기가 BLE로 접속하면 펌웨어가 거부하고 끊습니다. 0.4.0은 그 뒤 광고를 다시 시작하지 않아, 재부팅 전까지 iPhone이 다시 연결할 수 없었습니다.
- **광고 주기를 Apple 액세서리 권장값으로 바꿨습니다.** 부팅, 연결 끊김, 등록 요청 뒤 30초 동안은 20 ms, 그 뒤에는 152.5 ms로 광고합니다. 0.4.0은 160 ms 고정이었습니다.
- **광고 상태를 스스로 복구합니다.** 연결이 없는 동안 60초마다 광고를 다시 설정합니다.
- **연결 파라미터를 요청합니다.** 인증이 끝나면 연결 간격 30~45 ms, 감시 타임아웃 6초를 iPhone에 요청합니다. iPhone이 받아들이면 신호가 잠깐 약해져도 연결이 덜 끊깁니다. 거절해도 연결은 유지됩니다.

## 바뀌지 않은 것

- 설정 AP 이름과 비밀번호, Bluetooth PIN `123456`, 등록 창, 페어링 정보는 그대로입니다.
- MQTT 토픽과 Discovery, Home Assistant 엔티티, 저장된 설정 형식, 파티션 표도 바꾸지 않았습니다.
- Home Assistant 통합(HACS) 코드는 바꾸지 않고 버전만 0.6.16으로 올렸습니다.

## 업데이트

- **펌웨어:** HACS는 펌웨어를 업데이트하지 않습니다. 이번 수정은 ESP32에 펌웨어 0.4.1을 써야 적용됩니다.
  - 새로 설치할 때는 [설치 페이지](https://1bobby-git.github.io/HA-iOS-ANCS/)를 씁니다. 공장 초기화 이미지라서 기존 설정과 페어링이 지워질 수 있습니다.
  - 기존 기기를 업데이트할 때는 이 릴리스의 `.app.bin`을 각 칩의 `.json`에 적힌 앱 주소에만 쓰세요. 그러면 설정과 페어링이 유지됩니다.
- **Home Assistant 통합:** HACS에서 업데이트한 뒤 Home Assistant를 다시 시작합니다.
- **되돌리기:** v0.6.15 릴리스에 있는 펌웨어 0.4.0 이미지로 되돌릴 수 있습니다.

## 검증

- **저장소 테스트:** `tools/tests`와 `tests`를 Home Assistant 2026.7.0과 2026.10.4에서 실행합니다(Validate 워크플로).
- **펌웨어 빌드:** GitHub Actions Firmware 워크플로에서 ESP-IDF 6.0.2로 7종을 빌드하고 패키징했습니다. `finalize_firmware_release.py`가 7종의 이미지 해시, 메타데이터, 앱 ELF 지문을 대조했습니다.
- **확인하지 못한 것:** 실제 보드에서의 BLE 재연결, 광고 주기 전환, 연결 파라미터 협상, iPhone 알림 전달

## English summary

Firmware 0.4.1 fixes BLE reconnection. After an unenrolled peer connected and was rejected, firmware 0.4.0 never restarted advertising, so the iPhone could not reconnect until a reboot. Advertising now restarts after a rejected connection, uses Apple's recommended intervals (20 ms for 30 s after boot, disconnect or an enrollment request, then 152.5 ms instead of a fixed 160 ms), and is re-armed every 60 s while disconnected. After authentication the relay requests a 30-45 ms connection interval and a 6 s supervision timeout. Setup AP, BLE PIN, bonds, topics, entities, stored settings and partitions are unchanged. The companion integration only bumps its version. Hardware behaviour was not tested.
